# Проверка шага A на передатчике

Короткий чек-лист. Проходится за 10–15 минут, модель включать не обязательно для пунктов 1–3.

## 1. Установка

- [ ] `Apps/f3xc.lua` скопирован прямо в `Apps` на передатчике
- [ ] Передатчик перезагружен (выкл/вкл)
- [ ] `Menu → Applications → F3X Courses` открывается
- [ ] Заголовок формы — `F3X Courses 0.1.1`

**Если пункта нет:** файл не в `Apps`, имя файла другое, или не было перезагрузки.

## 2. Хранение курсов

- [ ] Виден один курс `My F3B course`
- [ ] Кнопка `Active` ставит звёздочку `*` в списке
- [ ] Поле `Name` меняется и сохраняется по кнопке `Save`
- [ ] После перезагрузки имя на месте
- [ ] Кнопка `New` без GPS даёт сообщение `No GPS position...` (это правильно, если модель выключена)

**Если имя не сохраняется:** проверить, что карта не защищена от записи; в `Apps/f3xc/` должен
появиться файл `courses.jsn`.

## 3. Телеметрийное окно

- [ ] В `Menu → Telemetry` (или в списке экранов) есть окно `F3X Courses`
- [ ] В окне видно имя активного курса, тип, дистанцию
- [ ] Видна строка `GPS no fix / not bound` (пока сенсоры не привязаны)

## 4. Сенсоры (нужна включённая модель)

На этой модели датчик уже известен: **`GPSLog3`**, Lat=3, Lon=4, Speed=5, Dir=9.

- [ ] `Sensors >>` открывается
- [ ] В заголовке написано `Sensor binding (N values)`, N > 0
- [ ] `Lat` сам указывает на `GPSLog3 / Latitude [LAT]` (профиль `KNOWN` подставил)
- [ ] `Lon` — `GPSLog3 / Longitude [LON]`
- [ ] `Speed` — `GPSLog3 / Speed [kmh]`
- [ ] `Dir` — `GPSLog3 / Flight Dir. [°]`
- [ ] В окне появились координаты и `to A xx.x m`

**Если вместо GPSLog3 выбрано что-то другое:** выбрать вручную из выпадающего списка.
`UniS-E / Altitude`, `Voltage`, `Vario` — это не GPS, их не выбирать.

**Если `No telemetry sensors found`:** телеметрия не идёт, сенсор не подключён к приёмнику
или приёмник не забинжен.

## 5. Создание курса с GPS

- [ ] На улице, с fix GPS: кнопка `New` создаёт курс
- [ ] В поле `A:` появились координаты
- [ ] В телеметрийном окне `to A` ≈ 0–5 м

## Что сообщить после проверки

1. Номер версии в заголовке (должно быть `0.1.1`).
2. Сколько значений показал список сенсоров (число в скобках).
3. Совпали ли Lat/Lon/Speed/Dir с `GPSLog3` (param 3/4/5/9).
4. Видно ли `to A` и меняется ли оно при ходьбе.
5. Любые сообщения об ошибках дословно.
