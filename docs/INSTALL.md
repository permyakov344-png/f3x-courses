# Установка и первый запуск

## 1. Куда копировать

На передатчике есть два места, куда можно положить приложение:

- **внутренняя память** передатчика — файлы видны как диск `Internal` при подключении по USB;
- **microSD-карта** — диск `SD`.

Оба варианта работают. Если карты нет — кладём во внутреннюю память.

Структура после копирования:

```
<диск>/
  Apps/
    f3xc.lua          <- файл приложения
    f3xc/             <- каталог данных (можно скопировать пустым)
```

Файл `f3xc.lua` должен лежать **прямо в `Apps`**, а не в подкаталоге. Каталог `Apps/f3xc/`
создаётся автоматически при первом запуске, если его нет.

## 1a. Главное: приложение надо ДОБАВИТЬ в активные

Скопированный файл — ещё не работающее приложение. В API 1.7, раздел
«Loading the applications»:

> The DC/DS-24 offers a simple overview of installed and active applications.
> See the menu **Applications – User Applications**. […] Using the **F(3) “Plus”** button
> you can activate additional Lua applications (**up to 10 can be active per model**
> at the same time).

Ключевой момент, на котором легко застрять: **F3 (Plus) открывает список
*доступных* файлов, а не активных приложений.** Само нажатие Плюса ничего не
добавляет. В открывшемся списке надо:

1. выделить строку `f3xc.lua` крутилкой;
2. **нажать саму крутилку** (Enter / кнопка 3D) — это и есть «добавить».

Только после этого файл становится активным приложением модели и появляется
в `Menu → Applications`.

Порядок целиком:

1. `Menu → Applications` → **F3 (Plus)** — откроется список доступных `.lua`/`.lc`.
2. Выделить `f3xc.lua`, нажать **крутилку**.
3. Если активных уже 10 — в списке активных выделить лишнее и нажать **F4 (Delete)**.
   Файл с карты при этом **не** удаляется, приложение просто выключено для модели.
4. `Menu → Applications` → `F3X Courses` → крутилка. Приложение откроется.

Перезагружать не обязательно: после добавления приложение запускается сразу.
Если пункта так и нет — см. `docs/TROUBLESHOOT-NO-MENU.md`: там разобраны причины
и что смотреть в журнале `Apps/f3xc/lastrun.txt`.

## 2. Установка с Windows

1. Подключить передатчик по USB, выбрать на нём режим `USB — Storage` (не Joystick).
2. В проводнике появится новый диск.
3. Открыть папку `Apps` на этом диске.
4. Скопировать туда `Apps/f3xc.lua` из репозитория.
5. Безопасно извлечь диск.

## 2a. Установка с macOS (скриптом)

На проверенном передатчике диск монтируется как `/Volumes/NO NAME`.

```bash
bash tools/install-to-tx.sh    # копирует f3xc.lua и диагностику sensors_dump.lua
```

Если macOS не смонтировал диск сам:

```bash
diskutil list | grep "NO NAME"      # найти, например, disk5s1
diskutil mount disk5s1
```

Перед копированием: `Menu → USB → USB Mass Storage` на передатчике.
Подробнее — `docs/TX-USB.md`.

Если папки `Apps` нет — создать её в корне диска.

## 3. Первый запуск

1. Добавить приложение в активные — см. п. 1a (**F3 Plus** → выделить `f3xc.lua`
   → нажать крутилку).
2. `Menu → Applications → F3X Courses` → крутилка.
3. Должна открыться форма с заголовком `F3X Courses 0.1.5`.

Если пункта нет — см. п. 1a и `docs/TROUBLESHOOT-NO-MENU.md`.

## 4. Привязка сенсоров

Без привязки GPS приложение показывает `GPS не привязан: нажмите F3` — это нормально.

1. Включить модель и приёмник, дождаться телеметрии на передатчике
   (в `Menu → Telemetry` должны быть видны значения GPS).
2. `Menu → Applications → F3X Courses → Датчики >>`.
3. В списках `Широта`, `Долгота`, `Скорость`, `Курс` выбрать нужные значения.
   Список содержит **все** телеметрические значения всех сенсоров в виде `Сенсор / Значение [единица]`.

На проверенной модели датчик — **`GPSLog3`**; приложение привязывает его само при первом
запуске (профиль `KNOWN`), достаточно убедиться, что выбраны:

| Поле | Строка в списке |
|---|---|
| Lat | `GPSLog3 / Latitude [LAT]` |
| Lon | `GPSLog3 / Longitude [LON]` |
| Speed | `GPSLog3 / Speed [kmh]` |
| Dir | `GPSLog3 / Flight Dir. [°]` |

Строки `UniS-E / Altitude`, `Voltage`, `Vario` — это не GPS, их выбирать не надо.
Полный разбор сенсоров записан в `SENSOR-NOTES.md`, п. 6.
   GPS-координаты обычно выглядят как `MGPS / Latitude [°]` и `MGPS / Longitude [°]`.
4. Выбор сохраняется сразу. Вернуться — кнопка `Back`.

`Dir` можно не заполнять: направление понадобится только на шаге C.

## 5. Первый курс

1. Выйти из модели на улицу (или хотя бы к окну) — нужен fix GPS.
2. `F3X Courses`, кнопка **New** — создастся курс с координатами текущей позиции в поле `A`.
3. Переименовать курс в поле `Name`, выставить `Type = F3B`, `Distance = 150`.
4. Кнопка **Active** — назначить курс активным (в списке появится `*`).
5. Кнопка **Save** — записать на карту и закрыть форму.

Проверка, что всё сохранилось: выключить и включить передатчик, снова открыть форму — курс
должен быть на месте, а в телеметрийном окне отображаться его имя.

## Если не появилось

| Симптом | Что проверить |
|---|---|
| Нет пункта в Applications | Файл лежит не прямо в `Apps`; имя файла не `f3xc.lua`; передатчик не перезагружали |
| Пункт есть, при открытии пустой экран | Ошибка Lua — подключить передатчик и посмотреть `Apps/f3xc/` на наличие файлов, проверить прошивку |
| `Датчики телеметрии не найдены.` | Модель выключена, телеметрия не идёт, или сенсор не зарегистрирован в приёмнике |
| `GPS не привязан: нажмите F3` | Не привязаны Lat/Lon, либо GPS ещё не получил fix (на улице 30–60 с) |
| Курс не сохраняется | SD-карта защищена от записи или заполнена |

## Удаление

Удалить `Apps/f3xc.lua` и каталог `Apps/f3xc/`. Больше ничего не трогается.
