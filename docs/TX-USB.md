# Передатчик по USB: как узнать имена датчиков

Короткий порядок, когда DS-24 подключён кабелем.

## 1. Включить режим USB на передатчике

`Menu → USB` → **USB Mass Storage** (не «USB Joystick», не «HID»).
Через пару секунд в `/Volumes` появится диск, обычно `JETI` или `DS-24`.
Если диск не появился — вынуть и вставить кабель, проверить, что кабель не «только заряжает».

## 2. Посмотреть, что уже есть

```bash
bash tools/scan-sensors.sh
```

Скрипт найдёт том (`/Volumes/NO NAME` или `JETI`), покажет каталог моделей `Model/`,
содержимое `Apps/`, и попробует вытащить имена датчиков из `.jsn` файлов моделей.
Дальше — два варианта.

## 3. Точно узнать имена — диагностикой с передатчика

Скрипт `strings` по `.jsn` может ничего не дать: JETI пишет телеметрию в бинарном виде.
Тогда работает одноразовая диагностика:

```bash
bash tools/install-to-tx.sh      # копирует Apps/F3x Courses.lua + Apps/sensors_dump.lua
```

Потом:

1. Отключить передатчик от компьютера, выключить/включить.
2. `Menu → Applications → F3X Sensors Dump`.
3. Экран покажет первые строки, полный список — в файле `Apps/f3xc/sensors.txt`.
4. Снова подключить по USB и забрать файл:

```bash
cp /Volumes/*/Apps/f3xc/sensors.txt ~/Desktop/
```

Формат файла:

```
idx | id | param | type | unit | label | value
  7 | 3  | 5     | 9    | deg  | Latitude  | 55.123456
```

Нужны строки с именами вроде `Latitude`, `Longitude`, `Speed`, `Heading`/`Course`,
и значение `id` (число) — по нему приложение и привязывает сенсор.

## Что делать с результатом

- Если в списке есть Lat/Lon — приложение привяжет их само (авто-подбор по названию);
  достаточно открыть `F3X Courses → Датчики >>` и проверить, что выбраны правильные строки.
- Если авто-подбор промахнулся — выбрать вручную из выпадающего списка.
- `sensors.txt` прислать сюда: по нему поправим эвристику авто-подбора и запишем
  точные имена в `docs/SENSOR-NOTES.md`.

## Важно

- `Apps/sensors_dump.lua` — диагностика, не часть приложения. Удалить её с карты
  можно в любой момент, на курсы и настройки она не влияет.
- Пишем только в `Apps/f3xc/`, модели и настройки передатчика не трогаем.
